## About Me

I'm a Full-Stack Software Engineer with 2+ years of experience building production systems with **Node.js, Express, TypeScript, and React**, and deploying them on **AWS with Docker and Kubernetes**. I take end-to-end ownership of features — architecting the API, designing the schema, and shipping the UI — rather than staying in one layer of the stack.

Most recently I led backend and CI/CD work at **Larsen & Toubro Infotech**, cutting deployment cycles by ~40% through GitHub Actions automation, and I hold an **MS in Information Systems from Northeastern University** (GPA 3.8/4.0).

I'm also a strong advocate for AI-assisted engineering workflows — I use tools like Claude and agent-first IDEs daily to move faster without cutting corners on system reliability.
